## SQL-инъекции

SQL-инъекция — это следствие смешивания SQL-кода и пользовательских данных.
Практика показывает: эксплуатация часто проста, а защита — тоже, если использовать параметризованные запросы.

Параметризованный (подготовленный) запрос — это SQL-шаблон, в котором структура команды отделена от передаваемых данных с помощью специальных заполнителей (например, ? или $1)
